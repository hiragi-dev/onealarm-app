# OneAlarm

**設定した場所まで歩かないと止められないアラーム。**

枕元でアラームを止めてまた寝てしまう、を構造的に不可能にするためのアプリです。
アラームは手元のスマートフォンではなく、離れた場所に置いた専用の機器（エッジデバイス）が鳴らします。
アプリから止めることはできず、あらかじめ登録した地点まで実際に移動して初めて鳴り止みます。

> **現在は開発中です。** 実機（MQTT ブローカー経由）に接続し、端末の位置情報と加速度センサーで動きます。

## はじめに: ホーム画面に追加してください

ブラウザのタブのまま使うと、**しばらく使わない間にアラームの設定が消えることがあります。**
また、後からホーム画面に追加してもそれまでの設定は引き継がれません。
設定を作る前に追加を済ませてください。

- **iPhone / iPad** … 共有ボタン → 「ホーム画面に追加」
- **Android / パソコン** … 画面下部に出る「インストール」から

## 画面の使い方

下部のタブで3つの画面を切り替えます。

### アラーム

登録したアラームの一覧です。右上の **＋** から追加できます。

| 項目             | 内容                                                             |
| ---------------- | ---------------------------------------------------------------- |
| 時刻             | 鳴らす時刻                                                       |
| 繰り返す曜日     | 1つ以上選びます                                                  |
| **停止方法**     | どこまで行けば止まるかを1つ選びます（**必須**）                  |
| 歩行検知を有効にする地点 | 設定すると、鳴っている間その地点に着くまで歩行検知が働きません |

行をタップすると編集、右のスイッチで有効・無効を切り替えられます。

停止方法がまだ1つも無いと登録できません。先に「停止」タブで作ってください。

### 停止

**アラームを止める** — アラームが鳴っている間、いま歩行を検知しているかと、
停止地点まであと何メートルかが表示されます。地点に着くと自動的に鳴り止みます。
歩いている間はアラームが一時停止するので、移動中に鳴り続けることはありません。
「歩行検知を有効にする地点」を設定したアラームでは、その地点に着くまで歩行検知が働かず、
着いた時点で有効になります（画面には「歩行検知オフ」と、あと何メートルかが出ます）。

止めるためのボタンはありません。移動する以外に止める方法はない、というのがこのアプリの考え方です。

**停止方法** — 「ここまで来たら止める」という地点を登録します。

1. 「追加」を押し、地図をタップして地点を選ぶ
2. スライダーで到達と見なす範囲（半径）を決める
3. 「次へ」で名前を付けて保存

一覧の項目をタップすると地図で場所を確認でき、そこから編集もできます。

### 設定

アラームを鳴らす機器との接続先（MQTT ブローカーの WebSocket URL、ユーザー名、パスワード、
デバイス ID）を設定します。設定と停止方法はこの端末のブラウザに保存されます。
パスワードもそのまま保存されるので、端末を共有する相手には見える前提で扱ってください。

## 気をつけていただきたいこと

- **アラームが鳴っている間は、そのアラームを変更・削除・無効化できません。**
  手元で設定を書き換えて止める、という抜け道を塞ぐためです。停止してから操作してください。
- **いずれかのアラームで使っている停止方法は削除できません。**
  消してしまうと、そのアラームを止める手段が無くなるためです。
- **鳴っている間は停止方法の場所を変更できません。**
  鳴っている最中に停止地点を今いる場所へ動かせてしまうためです。

## 動作環境

iOS / Android の各ブラウザと、パソコンのブラウザに対応しています。
位置情報と歩行検知（加速度センサー）を使うため、初回に利用許可を求めます。
どちらも HTTPS（または localhost）でしか使えません。開発中に同じ Wi-Fi のスマホから
PC の IP で開くときは、`npm run cert:renew` で自己署名証明書を作ってから `npm run dev` を
起動すると HTTPS になります（初回はブラウザの警告を進めてください）。

開発ツールを含まない本番ビルドをスマホから使うには `npm run serve` を実行し、
表示される `https://<PC の IP>:4173/` を開きます（dev サーバーとは別のサイト扱いなので、
設定と停止方法は入れ直しになります）。

## 公開版

main に push すると GitHub Actions が GitHub Pages へ配信します
（`.github/workflows/deploy.yml`）。公開先は https://hiragi-dev.github.io/onealarm-app/ です。
こちらは正規の HTTPS なので証明書の警告は出ず、ホーム画面に追加すれば PC 無しで使えます。
どちらも端末の中だけで処理し、外部へ送信することはありません。
